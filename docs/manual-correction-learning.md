# 手動修正學習

語音輸入後，使用者在同一輸入框修改辨識錯字，稍停後按 Enter 或 Ctrl+Enter 送出。程式確認該欄位清空後，學習本次語音範圍內的小段替換；學到的內容顯示於「辨識紀錄」。中文字詞與英文寫法加入熱詞；單一中文字使用智慧選字前後文記錄。

## 目前範圍

- 採用 Windows 共用的輸入欄位讀取介面，不以程式名稱限制常見文字框。
- 必須確認貼入前後是同一欄位，且差異確實為本次語音文字。
- 僅學替換；新增、刪除、大幅重寫與欄位外的變動會跳過。
- Shift+Enter 換行、輸入法確認、Enter 後未清空的欄位不觸發學習。
- 快速修改後立即送出而尚未取得最後版本時會跳過；送出按鍵照常傳遞。
- 終端機、密碼欄位、無法讀取文字的自繪欄位、滑鼠送出目前不支援。編輯文件而沒有送出／清空動作也不會觸發。
- 不攔截或重送使用者的 Enter。監控失敗不應阻止語音文字貼入。

## 資料及測試

只追蹤最近一次已驗證的語音輸入範圍，有效期有限。切換欄位、程式代為替換、刪除剛輸入的文字等操作取消來源。測試使用合成欄位快照及暫存詞庫，不讀取真人輸入框，也不寫入真實詞庫。

此功能無法保證所有程式都有可讀取的文字介面。手動新增熱詞及選字選單仍可用於自動學習未涵蓋的欄位。
