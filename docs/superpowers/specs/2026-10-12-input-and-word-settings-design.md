# VoiceInput 錄音與詞庫修正方案

## 使用者目標

錄音鍵保持「右 Alt」，左 Alt 維持一般鍵盤用途。滑鼠映射必須能發送對應右 Alt，實際事件尚待確認。

錄音結束後，成功、空白結果及辨識失敗都可在辨識紀錄中查到；模型例外顯示簡短提示。修正双擊刪除殘留錄音，維持既有按一下、連按兩下及按住的規則。

## 熱詞操作

建議在現有「熱詞」頁加入輸入框與「加入」按鈕，Enter 也能加入。每列提供「編輯」及既有刪除操作。修改成功立即儲存並在下一段語音使用，不需重啟。

重複詞沿用同一筆，手動加入升為手動詞與目前上限（中文 5、英文 3）。編輯採一次修改，避免先刪後加；保留原加入日期。單一中文字仍由智慧選字學習，介面說明限制。無法被目前模型編碼的詞顯示提示。

替代方案：整個詞庫都用內建表格編輯器。可集中編輯權重和智慧選字前後文，但本次所需介面與驗證範圍更大；建議先使用現有熱詞頁。

## 外部檔案與智慧選字

「開啟紀錄檔」明確使用記事本，避免依賴 Windows 的 JSON 檔案關聯。現有選字資料格式與學習規則保留。

讀取詞庫及儲存前檢查檔案更新，完整解析有效版本後換入；外部格式錯誤保留最後有效內容，顯示錯誤並阻止覆寫原檔。儲存使用暫存檔替換，檢查外部版本衝突。

## 辨識錯誤

已有三次 ONNX Reshape 錯誤的日誌證據。查明模型觸發條件後修正，禁止僅因猜測調整模型或丟棄語音。錯誤紀錄含時間、錄音秒數及可讀原因；完整技術原因留在應用日誌。新診斷資料不儲存原始音訊。

## 驗證與交付

使用隔離的暫存詞庫驗證新增、編輯、持久化、外部修改及格式錯誤保護。假錄音器驗證雙擊狀態與辨識例外；合成語音測試真實模型。實際設定視窗確認新增及記事本開檔。真人測試確認右 Alt、滑鼠映射與語音效果。

程式碼保留在 fix/mouse-remapped-alt 分支。每次提交後重啟 VoiceInput 並檢查新的「就緒」日誌。
